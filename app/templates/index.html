What happens to your file

  1. The file signature is checked, so a renamed file is rejected rather than OCR'd.
  2. Images are auto-rotated, greyscaled and upscaled for better accuracy.
  3. For PDFs, pages that already contain a text layer are read directly; the rest is rendered at {{ limits.dpi }} DPI and passed through Tesseract.
  4. The extracted text is shown per page and can be copied or downloaded as .txt.
